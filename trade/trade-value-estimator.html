Torn Trade Value Estimator

Paste a Torn trade description to estimate the total value of its items using Torn's current item market-price data.

The key is sent directly to Torn's API for the item catalog request. This page does not store it or send it to any other service.

The parser reads quantity-and-name pairs such as “1383x African Violet”. Unrecognized or unpriced items are shown separately rather than counted as zero.

For example, 97% means paying 97% of market price. Discounted unit prices are rounded to the nearest dollar.
